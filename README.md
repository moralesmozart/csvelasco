# CSV Aduaneiro

Landing page da CSV Aduaneiro (Claudio Velasco), parceiro técnico de desembaraço aduaneiro para importadoras, tradings e assessorias de comércio exterior.

Site estático de um arquivo só (`index.html`), sem build. Publicado via GitHub Pages: https://moralesmozart.github.io/csvelasco/

## Estrutura
- `index.html` – página completa (HTML, CSS e JS inline; animação do porto em canvas; simulador).
- `favicon.svg` – bandeira Q (pedido de livre prática no código internacional de sinais).
- `og-image-v2.jpg` – prévia para WhatsApp/LinkedIn (1200×630, JPEG ~75 KB). Ao trocar a imagem, use um nome novo (v3, v4...) para furar o cache do WhatsApp.

## Antes de tornar público
- [ ] Remover `<meta name="robots" content="noindex, nofollow">` do `index.html`.
- [ ] Remover a faixa "RASCUNHO" do topo.
- [ ] Preencher os campos marcados em amarelo: WhatsApp, e-mail, CNPJ, endereço.
- [ ] Confirmar habilitação de despachante aduaneiro e a citação ao Centro de Aramar.
- [ ] Validar com Claudio os números do cenário "com a CSV" no simulador.
- [ ] Adicionar foto e logotipo oficiais.
- [ ] Domínio próprio (ex.: csvaduaneiro.com.br) e atualizar URLs de `canonical`/`og:*`.
